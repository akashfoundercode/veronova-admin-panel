# Veronova Admin Panel (practice UI)

React + Vite + Tailwind CSS v3 + React Router + Recharts + lucide-react.
All data is local mock data (no backend).

    npm install
    npm run dev

Pages: Dashboard, Attendance, Players, Fund Transfer, VIP Levels, Illegal Bets, System Users,
Login/Today IP Logs, Aviator Game, Aviator Settings, MLM Levels, Salary, Colour Prediction,
Chicken Road (Multiplier / Bet History / Bet Values / Amount Setup), Gift, Banners.
Other sidebar items use a generic list page (Simple.jsx).

The Aviator Game page runs the SkyRush interface as an isolated, local demo. Its rounds, bets,
wallet balance, recent results, and other players are simulated in the browser; no game API or
socket connection is used. Aviator mode settings remain available under Games → Aviator Settings.
